# Surface brief: ProofMart home (and the world it sets for the whole product)

Scope: home `/` is Persuade; security is Read; auth, documents, report and account are Operate surfaces inheriting this world at restrained intensity.
Audience: developer-led (engineer at an Indian lender/fintech integrating /v1/verify); reviewers (underwriters, risk) read the reports.
Action: run the sample / drop a PDF; get an API key. Proof: the live Evidence Rail on the bundled SAMPLE statement; the six real markers; the real API, webhooks, signed dossier, CLI.
Constraints: honesty rules (no invented customers, metrics, certifications; SAMPLE labels), fonts self-hosted via next/font, India-first (INR, Indian statements), Evidence Rail stays central.

## Direction contract

THESIS: The report is a chartered accountant's working paper: every figure footed, cross-footed and ticked, every break circled in red pencil with the sum that disproves it. Refuses the dark dev-tool landing (headline + buttons + code block) and the AI-trust gradient.

OWN-WORLD: Pale green columnar analysis paper (#e6ecdf) with faint row rules and stronger column rules, double rules closing a sheet; graphite ink (#26282b) for type and figures; red pencil (#c8321e) only for exceptions and FAIL; blue pencil (#1f4f9a) for queries and REVIEW; graphite tick for CLEAR. An authored SVG tickmark set (tick, footed, cross-footed, query, break, circle) is the icon system. Libre Franklin for headings and UI, JetBrains Mono for figures, code and identifiers. Square corners, no shadows except the sheet lying on the desk.

STORY: The visitor sees a real statement being audited, sees the verdict, opens the evidence (page, row, arithmetic), runs the same check through the API, and wires it in with webhooks, dossiers and the CLI. They believe it because every claim is a tick they can check.

FIRST VIEWPORT: Pad header strip (wordmark left, nav, W/P stamp right). Left 45%: sheet title "Footed, cross-footed, ticked." at ~6rem with "ticked." in red pencil, one-paragraph subcopy, primary "Check a statement" (opens the Evidence Rail sample / PDF drop) and secondary "Read the API". Right 55%: the SAMPLE statement page as a columnar schedule; rows tick down in graphite, row 17 is struck and circled in red with the margin note "84,210 + 12,500 = 96,710" and BALANCE_BREAK p4 r17. Tickmark legend runs along the foot of the viewport.

FORM: Audit Working Paper, position 1 on my ordered list (picked by the user over the rolled Reservation Chart); seed key 12fd0b8a.

SIGNATURE: Selecting a finding turns the sheet to its page and row, and the red-pencil circle draws itself round the disputed figure while the margin note writes the arithmetic. Motion grammar: pencil strokes draw (stroke-dashoffset, expo ease-out); one tick cascade on first view; reduced motion shows marks already drawn.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
